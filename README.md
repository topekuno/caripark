# CariPark

Simple KL parking tips for everyone — **Good / Okay / Skip**.

**Live:** https://park.topekuno.my

## Preview

```bash
python3 -m http.server 8080
```

## Data

`data/spots.json` is a snapshot from Notion with kid-friendly titles and one-line tips. Prices are short “about RM…” notes (2024–2026 social snapshots).
