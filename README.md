# CariPark

Simple public website for **CariPark** — find the best parking in Kuala Lumpur and Malaysia from local social insights.

## Preview locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Stack

Static HTML + CSS (+ tiny vanilla JS for the year). No build step.

## Status

v1 landing page. Waitlist form is a placeholder (no backend yet).
